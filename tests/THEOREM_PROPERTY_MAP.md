# The Admissible theorem system — executable property map

Every proved statement of the four-layer kernel, mapped to the property that asserts it
against the **live kernel** on every commit. Generated from an adversarial inventory of
`paper/PROOFS.md` (I), `paper/RGA/PROOFS.md` (R, V), `paper/RGA/INVARIANTS.md` (C, E), and
`paper/admissible/DRAFT.md` (Theorem 1/2), cross-checked against the kernel sites and the
existing example tests.

**80 labels — no slack.** 73 fully property-testable, 6 partial, 1 example-only.
