# Custody theory — the capability catalogue

Companion to `DRAFT.md` §8. Every entry names the theorem it comes from, the code site it lands on, its tier in the kernel's own cost vocabulary, what `custody.py` already computes for it, and its verification status. Status vocabulary: **computed** — the companion computes it over real kernel runs and `tests/test_custody.py` checks it; **derived** — follows from a proved theorem, no code; **proposed** — a design with a stated caveat; **conjectural** — believed, not proved; **reproduced** — a kernel finding re-executed by a referee and by the test suite; **restated** — an existing kernel rule in the theory's vocabulary, no new computation.

Tiers: *formalize-only* (paper), *new-query* (a pure function over journal state the kernel already keeps; writes nothing; the cheapest and most in-culture tier), *new-guard* (a refusal or publication on an existing transition), *new-protocol* (a new root field, event, or signed object), *tooling* (test/verification infrastructure).

None of the twenty-eight changes what `admissible(id)` returns today, except N28, a semantics change to the standing layer that the standing paper would have to adopt in three places. Each respects R11/C7: queries write nothing, and a guard or protocol lives in the machine that owns the field.

## Findings

`DRAFT.md` §8a lists fourteen findings about the kernel as it is (F1–F14), each predicted by a theorem, executed against the unmodified code by an adversarial referee (`REVIEWS.md`), and re-executed by `tests/test_custody.py` for every row but F9, F10 and F13 (`FindingF1DiscreditIsFailOpen`, `FindingF1RefusalPath`, `FindingF2ReplaySeam`, `FindingF3RollbackWritesTheLowerMachine`, `FindingF4UnregisteredPairCut` with both pair cuts and the off-diagonal, `FindingF5InstallCoverageNotRecomputed`, `FindingF6SortlessFloor`, `FindingF7CalOpenLeavesNoTrace`, `FindingF8EscapeAtThePublishedTrialPoint`, `FindingF11UnmediatedSealIsUnanchored`, `PositionWitnessT12` for F12, `FindingF14RefusedCheckerAcceptedOnRebuild`). The one an online party can drive alone is F1; its repair is N28.

## Reading the table

The computed and reproduced rows are the ones a reviewer can take into the kernel in the kernel's style — a named pure function with a red-first test — without a protocol change; each carries a theorem and each is already exercised against real three-layer runs by `tests/test_custody.py`. The two rows that change what an offline adversary can forge (N2, N7) are the ones aimed at the composed paper's largest named residue. The rows that change what a seal or budget *says* (N5, N12) do so with primaries.

## What the catalogue does not claim

No row converts procedure into truth, a primary into a rate, or a survived attack into correctness. N4's figures are readings under the uniform within-model reading (D14) and say nothing about coupling to real defects (B6). N2 must be signed, and signer custody is B14. N7 and N10 are designs with stated caveats, not guards. N3's completeness is conjectural. Nothing here makes any gate reachable.
