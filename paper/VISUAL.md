# Author visual

Roque Briceño. Interpretation of fail-closed class dispatch, not a name and not a build ticket.

You take an object, put the prompt and accepted project inputs in, and it takes form. At each stage it either holds or breaks. On a break it may ask you, or retry that stage with another allowed model. When the shape holds through every required stage it becomes an accepted artifact and may update the accepted project memory.

Many objects can form at once. Each pins the project shape it started from. When one is accepted, the project changes; other active objects do not absorb that change silently. They either continue under a signed impact review or reopen against the newer shape.

That picture maps onto: work item, pinned context envelope, fail closed, retry inside the allow set, accepted artifact, accepted-only memory promotion.

Not node-graph circles. Not a 3D task.
